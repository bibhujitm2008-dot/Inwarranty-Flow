# Postman API Automation Integration with Github Actions #

This repository is a demonstration for POC for integrating postman tests with github actions.
Github actions will trigger the project execution on every push to main branch.

## Tech Stack ##
1. Postman
2. Newman
3. Newman-Reporter-Htmlextra
4. NodeJs 22v
5. Github Actions
6. Github pages

## Testing Coverage ##
1. Happy Flow
2. Edge Case
3. Token testing
4. Schema Validations
